# 微信聊天记录导出工具（macOS）

把电脑微信里**当前打开的会话**导出成 **Word（.docx）** 和 **Markdown（.md）**，
带聊天文字、图片、时间，仿微信左右气泡排版，方便存档和整理客户需求 / 喂给 AI 分析。

- **不解密、不碰数据库、不动 SIP、不改微信**——纯靠"读屏 + 自动滚动截图 + OCR"，最安全。
- 全程**本地离线**，不联网、不上传任何数据。
- 文字用 macOS 原生 OCR 识别，可在 Word 里直接编辑、复制、批注。

---

## 一、怎么启动

### ✅ 方式 A：双击 App（推荐）
双击 **`微信导出.app`** → 弹出图形界面。

> **首次运行要授权**：App 第一次抓取时，macOS 会提示需要权限。请到
> **系统设置 → 隐私与安全性**，在 **辅助功能** 和 **屏幕录制** 两个列表里，
> 把 **「微信导出」** 都打开，然后回到 App 再点一次「开始抓取」。（只需授权一次）
>
> 若双击提示"来自身份不明的开发者"：**右键 App → 打开 → 再点打开**，之后就能直接双击。

### 方式 B：备用启动（最稳，用终端已有权限）
双击 **`启动App(备用).command`**，会通过终端打开同一个图形界面。
（如果方式 A 的权限一时搞不定，用这个）

### 方式 C：命令行（全量自动，不用手选）
```bash
cd ~/聊天导出
./.venv/bin/python wxexport.py --format docx,md          # 自动识别会话名，导两种格式
./.venv/bin/python wxexport.py --name 客户张三 --voice    # 自定义名 + 语音转文字
```

## 二、App 使用流程

1. 在微信里**点开要导出的会话**（客户 / 群）
2. 打开本 App，点 **「开始抓取」**（窗口会自动最小化，微信自动滚动，**期间别碰鼠标键盘**）
3. 想中途停下：按 **⌃⌥⌘ + .（句号）**，或在 Dock 里点开本 App、按红色 **「停止抓取」** 按钮
4. 抓完后 App 自动回到前台，出现**预览长图**：**点一条消息作「开始」，再点一条作「结束」** → 只导这一段（不点则导出整段）
5. 勾选要的格式（Word / Markdown），点 **「导出」**
6. 点「打开导出文件夹」查看结果（设置会自动记住，下次不用重新勾）

## 三、输出

所有导出文件统一放在 **`导出结果/`** 文件夹：

- `会话名_聊天记录.docx` —— Word 文档（仿微信气泡排版）
- `会话名_聊天记录.md` —— Markdown（AI 友好，图片按路径引用）
- `会话名_聊天记录_图片/` —— 抠出的所有图片/视频封面

导出内容会自动做这些清理：

- 气泡里**因宽度自动折行的句子合并成完整段落**（自己按回车分的行会保留）
- 滚动拼接产生的**重复文字 / 重复时间分隔自动去重**
- 居中的时间戳、"已建群"、撤回提示等**系统消息不再误算成"对方"的发言**
- **群聊**里尽量识别气泡上方的**成员昵称**（识别不到时仍显示"对方"）

## 四、已知限制

- **文字靠 OCR**：99% 的中文/英文/数字/网址都准，但表情图标、花体字偶有个位数误识别，导出后扫一眼即可。
- **语音转文字**：勾选后会自动右键调用微信自带「转文字」（先确认菜单里有该项才点，误判不会误操作）。属实验功能，较慢，建议先在有语音的会话试跑验证。
- **群聊昵称**是按屏幕小字标签识别的，偶尔漏识别时该条会显示为"对方"或沿用上一条的名字。
- **很长的会话**滚动抓取会花几分钟；App 里可调「最多滚动屏数」。
- 抓取时微信会被切到前台自动滚动，**期间不要操作电脑**。

## 五、技术说明

`前台化微信 → 滚到最新 → 逐屏截图并按像素位移拼成整段长图 → 分片 OCR 提取文字 →
按气泡颜色区分我/对方、识别时间戳/系统消息/群聊昵称、抠出图片 → 渲染成 Word / Markdown`

| 文件 | 作用 |
|------|------|
| `微信导出.app` | 桌面应用（AppleScript 外壳启动下面的 app.py）|
| `app.py` | 图形界面（pywebview，抓取/预览/点选/导出）|
| `engine.py` | 抓取+解析引擎（App 和 CLI 共用）|
| `wechat_ui.py` | 驱动微信（前台化/滚动/截帧/位移匹配/停止控制）|
| `geometry.py` | 定位聊天区 |
| `ocr.py` | macOS Vision OCR（长图分片以保准确度）|
| `parse3.py` | 解析（气泡连通域/时间戳/昵称/去重/折行合并）|
| `render_docx.py` / `render_md.py` | 排版输出 |
| `voice.py` | 语音自动转文字 |
| `wxexport.py` | 命令行版 |
| `导出结果/` | 所有导出的文档和图片 |
| `_tmp/` | 运行时的截图/拼接图等临时文件，可随时整个删除 |

依赖装在 `.venv/`（pyobjc / Vision / scipy / python-docx / Pillow / numpy / pywebview）。
