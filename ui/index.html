微信聊天记录导出

把微信当前打开的会话导出成 Word / Markdown · 本地运行不联网
先在微信里 点开要导出的会话，并把聊天滚到你想开始的位置。点「开始抓取」后，会从当前顶部位置往下抓到最新消息。抓取时自动滚动微信，期间请勿操作鼠标键盘。
⛔ 想中途停下：按 ⌃⌥⌘ + .（句号）；或在 Dock 里点开本 App，按「停止抓取」。
